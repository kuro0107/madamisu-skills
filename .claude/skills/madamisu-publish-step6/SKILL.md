以下の手順でmadamisu-publishの工程6（修正反映）を実行してください。

## 引数の解析

- 第1引数（必須）: `INPUT_DIR`
- `--v N` オプション: `PUBLISH_V`

## 入力ファイル読み込み

Read ツールで:
- `publish/v{PUBLISH_V}/05_review_report.md`
- `publish/v{PUBLISH_V}/04_*.md`

## 分類エージェント起動

```
あなたはmadamisu-publishの修正分類エージェントです。

【入力】
publish/v{PUBLISH_V}/05_review_report.md

【タスク】
各問題を以下4分類に振り分け:
- 軽微: 校正、表現調整 → 自動修正
- 資料レベル: 情報追加・調整 → 自動修正
- 設計レベル: ルール構造、フェーズ構成、情報開示マトリクスの問題 → ユーザー確認
- 前提レベル: 世界観・キャラ・真相の問題 → ユーザー停止

【ストレステスト判断基準】
| 種別 | 致命度 | 分類 |
|---|---|---|
| メタ読み確信度70%以上 | 高 | 設計レベル |
| メタ読み50-70% | 中 | 資料レベル |
| メタ読み50%未満 | 低 | 許容 |
| 暴走完全破綻 | 高 | 設計レベル |
| 暴走一部破綻 | 中 | 資料レベル |
| 消極的完全詰み | 高 | 設計レベル |
| 消極的一部目標不能 | 中 | 資料レベル |

【出力】
publish/v{PUBLISH_V}/_working/06_classification.md に以下のフォーマットで保存:

# 修正分類結果

## 軽微（自動修正対象）
- 問題1: ...

## 資料レベル（自動修正対象）
- 問題1: ファイル: ... / 内容: ... / 修正案: ...

## 設計レベル（ユーザー確認必要）
- 問題1: ...

## 前提レベル（ユーザー停止）
- 問題1: ...

最終行: 設計レベル: N件 / 前提レベル: N件
```

## 自動修正実行（軽微・資料レベル）

`publish/v{PUBLISH_V}/_working/06_classification.md` から「軽微」と「資料レベル」の問題を抽出。

修正エージェントを起動:

```
あなたはmadamisu-publishの修正エージェントです。

【入力】
publish/v{PUBLISH_V}/_working/06_classification.md
該当ファイル（軽微・資料レベル問題のファイル群）

【タスク】
各問題を該当ファイルに Edit ツールで反映。
変更箇所に HTML コメント <!-- Review v{PUBLISH_V}: 問題内容要約 → 修正 --> を付加。

【出力】
publish/v{PUBLISH_V}/_working/06_auto_fix_log.md に修正ログを保存。
```

## 設計レベル: ユーザー確認

`06_classification.md` から設計レベル件数を取得。0件ならスキップ。

1件以上ある場合、以下を表示:

```
設計レベルの問題がN件あります:
1. {問題1}
2. {問題2}
...

工程2に戻ってルール設計を修正しますか？ [y/n/skip]
  y: 工程2に戻り部分更新
  n: 中断
  skip: 設計レベルは無視して次へ（推奨されない）
```

ユーザー入力後:
- `y`: 設計レベル問題を要約した `FEEDBACK` を生成し、Read で `.claude/commands/madamisu-publish-step2.md` を読み込み `{INPUT_DIR}` `--v {PUBLISH_V}` `--feedback "{FEEDBACK}"` で実行 → 工程3 → 工程4 → 工程5 → 工程6 ループ。ループ回数を `LOOP_COUNT` でカウント、3回超で「修正が収束しません。ユーザーに相談してください。」と表示して停止。
- `n`: 「処理を中断しました」と表示して終了
- `skip`: そのまま次へ

## 前提レベル: 停止

`06_classification.md` から前提レベル件数を取得。1件以上ある場合、以下を表示して停止:

```
前提資料レベルの問題が見つかりました:
- {問題1}
...

これは madamisu の設定資料側の問題です。以下のいずれかで対応してください:
1. madamisu 側で修正（/madamisu-feedback --v <元v番号> "<内容>"）
2. 設定資料を手動編集
3. 問題を無視して進める（推奨されない）

対応後、再度 /madamisu-publish-step5 または /madamisu-publish-step6 を実行してください。
```

## 修正後の差分レビュー（γ）

軽微・資料レベル修正完了後、Agent で:

```
あなたはmadamisu-publishの差分レビュアーです。

【入力】
publish/v{PUBLISH_V}/_working/06_auto_fix_log.md
修正された各ファイル

【タスク】
修正により他箇所との整合性が崩れていないか限定的にチェック。
影響範囲のファイルのみを対象とする。

【出力】
publish/v{PUBLISH_V}/_working/06_diff_review.md に保存:
🔴致命的 / 🟡軽微 件数を最終行に記載。
```

🔴致命的が0件なら工程7へ。1件以上残っていれば再修正（軽微・資料レベル）→ 再差分レビュー、最大2回。

## 完了表示

```
========================================

修正ログ: publish/v{PUBLISH_V}/_working/06_auto_fix_log.md
```

## 完了条件

全問題対応完了、または設計レベル以上は明示的にユーザー判断済。
