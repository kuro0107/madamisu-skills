# Phase 3 制作方針レビュー観点

タイムラインが制作方針に整合しているかを評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 方針遵守度（タイムライン）（10点満点）

- [ ] 想定プレイ時間とタイムラインの密度が一致
- [ ] 難易度指定がアリバイ複雑度に反映されている
- [ ] 雰囲気指定が時刻設定や場所配置に反映されている
- [ ] ジャンル指定がタイムラインのドラマ構造に反映されている
- [ ] 重視軸指定(謎/キャラ/世界観)に応じた時刻配分
- [ ] PvP指定時、対立構造を生む時刻配置がある
- [ ] 協力型指定時、協力可能な時間帯が設計されている
- [ ] 初心者向け指定時、推理補助になる目印(タイムスタンプ等)がある
- [ ] 上級者向け指定時、推理を阻害しない範囲の複雑さ
- [ ] エンディング構成に応じた分岐時刻の設計

## 構造整合性（10点満点）

- [ ] プレイ人数すべてのタイムラインが記述されている
- [ ] GMあり指定時、GMの判定タイミングが明示されている
- [ ] GMレス指定時、進行マイルストーンが明示されている
- [ ] 各キャラに最低1つの重要時刻が割り当てられている
- [ ] 全タイムラインを統合して矛盾なく成立する
- [ ] 真犯人のタイムラインが他キャラと整合する
- [ ] 証拠発生時刻と事件発生時刻が整合する
- [ ] 場所配置がキャラの動線として成立する
- [ ] タイムラインがプロット（Phase 2）と整合する
- [ ] タイムラインの最終時刻がエンディング条件と紐付く

## 固定要素遵守（10点満点）

- [ ] Q12 固定要素がタイムラインに反映されている
- [ ] Q9 禁止事項に違反する場面がタイムラインにない
- [ ] 元資料の重要場面（あれば）がタイムラインに含まれる
- [ ] 元資料の時間軸（あれば）と整合する
- [ ] タイムラインで元資料の雰囲気が崩されていない
- [ ] 元資料の重要キャラの活躍タイミングが確保されている
- [ ] 元資料のテーマがタイムライン構造に反映されている
- [ ] 固定要素が時刻に紐付いて明示されている
- [ ] ユーザー指定のトーン（Q5補足等）がエンディング時刻に反映
- [ ] タイムライン全体で制作方針との整合が崩れていない

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 3観点の平均値（小数第1位切り捨て）。
