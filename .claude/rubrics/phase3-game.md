# Phase 3 ゲーム性レビュー観点（タイムライン）

タイムラインの論理的整合性を評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## アリバイ整合性（10点満点）

- [ ] 各キャラの行動が時刻ごとに記述されている
- [ ] 同一キャラが同時刻に複数場所にいない
- [ ] 各時刻に最低1人の所在が把握可能
- [ ] アリバイを証言する「証人」が明示されている
- [ ] アリバイのない時間帯が真犯人特定に繋がる
- [ ] 真犯人のアリバイに「崩せる弱点」が設計されている
- [ ] 偽アリバイ（他キャラが嘘をつくケース）が明示されている
- [ ] 移動時間が物理的に成立する
- [ ] 全キャラのタイムラインが時刻順に並んでいる
- [ ] アリバイの証言と物的証拠が照合可能

## 証拠の発見可能性（10点満点）

- [ ] 各証拠の発生時刻が明記されている
- [ ] 各証拠の発生場所が明記されている
- [ ] 証拠の発見条件（誰が・どこで・どうやって）が明記
- [ ] 重要証拠が複数プレイヤーに発見可能
- [ ] 証拠の発見が特定キャラに偏らない
- [ ] 証拠が時系列で意味を持つ（順序関係がある）
- [ ] 真犯人だけが知る証拠が明示されている
- [ ] 証拠が「発生」「発見」「解釈」の段階で分けられる
- [ ] 偽証拠と真正証拠の発見ルートが区別可能
- [ ] 証拠発見が捜索フェーズで実現可能

## 真犯人の行動の実現可能性（10点満点）

- [ ] 真犯人が事件を起こす時間がタイムラインに確保されている
- [ ] 真犯人の機会・手段・動機が時系列で繋がる
- [ ] 真犯人の移動経路が物理的に成立する
- [ ] 真犯人が証拠を偽造する時間が確保されている
- [ ] 真犯人の偽アリバイ工作の手順が記述可能
- [ ] 真犯人の行動が他キャラに目撃されない理由が説明可能
- [ ] 真犯人の犯行手段の物理的な実行可能性
- [ ] 真犯人の犯行後の行動が自然
- [ ] 真犯人の心理的動揺が他キャラに察知される/されない理由
- [ ] 真犯人特定後に振り返って「あの時の行動」が伏線になっている

## 推理の公平性（10点満点）

- [ ] タイムラインから真相に到達する論理パスが存在する
- [ ] 真相到達に「全タイムラインの統合」が必要な設計
- [ ] 各プレイヤーが自分のタイムラインを通じて貢献可能
- [ ] 推理に外部知識（マダミス経験等）が不要
- [ ] タイムラインの時刻表記が一貫している（24時間制等）
- [ ] 時刻の刻みが推理に適切（粗すぎず細かすぎず）
- [ ] アリバイ崩しの手がかりが多すぎず少なすぎない
- [ ] タイムラインから「推理可能な真相」が一意に決まる
- [ ] 偽の真相に誘導されるルートが排除されている
- [ ] エンディング条件達成がタイムラインの理解に基づく

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 4観点の平均値（小数第1位切り捨て）。
