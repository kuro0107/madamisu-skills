# Phase 1 世界観レビュー観点

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 世界観の深み（10点満点）

- [ ] 舞台設定の歴史的・文化的背景が記述されている
- [ ] 舞台特有のルールや慣習が3つ以上設計されている
- [ ] 世界観に矛盾する要素がない
- [ ] 舞台が物語の核に関与している（単なる背景ではない）
- [ ] 時代設定と文化描写が整合している
- [ ] 世界観の「禁忌」や「制約」が明示されている
- [ ] 舞台特有の専門用語や固有名詞が設計されている
- [ ] 舞台の物理的構造（場所配置）が記述可能なレベルにある
- [ ] 世界観のトーン（雰囲気）が一貫している
- [ ] プレイヤーが没入できるディテールがある

## キャラクターの魅力（10点満点）

- [ ] 各キャラクターの職業・立場が明確
- [ ] 各キャラクターに個別の性格特徴がある
- [ ] キャラクター間の関係性が複層的に設計されている
- [ ] 各キャラクターに事件以外の人生背景がある
- [ ] 動機の根が「人間的」である（陳腐な悪役でない）
- [ ] 各キャラクターに弱点や葛藤がある
- [ ] キャラクター名が世界観と整合している
- [ ] 性別・年齢・外見の設定が偏っていない（必然性ある偏りは除く）
- [ ] 各キャラの「秘密」が他のキャラと連動している
- [ ] プレイヤーが演じたくなる魅力がある

## 独自性（10点満点）

- [ ] 設定がチープでない（テンプレ的でない）
- [ ] 元資料の独自要素が世界観に反映されている
- [ ] 他のマダミス世界観と区別できる要素がある
- [ ] 舞台と事件の組み合わせに必然性がある
- [ ] キャラクター構成に独自性がある
- [ ] 世界観の「ねじれ」や「特殊性」が設計されている
- [ ] 既存ジャンルの単純な踏襲ではない
- [ ] テーマ的な深みがある
- [ ] 舞台特有のドラマが生まれる構造
- [ ] 「この世界観でしかできない」物語要素がある

## 雰囲気（10点満点）

- [ ] 制作方針の「雰囲気」指定（コミカル/シリアス等）と一致する
- [ ] 緊張感が生まれる場面が設計されている
- [ ] 没入感を阻害する要素がない（メタ的破綻なし）
- [ ] トーンが世界観全体で一貫している
- [ ] BGM・小道具・天候など演出的要素が示唆されている
- [ ] キャラクターの言動が雰囲気に沿っている
- [ ] 場面転換に意味がある
- [ ] 制作方針のジャンルに沿った要素が含まれる
- [ ] プレイ時間に対して密度が適切（長すぎ・薄すぎがない）
- [ ] エンディングのトーンが事件全体の雰囲気と整合する

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 4観点の平均値（小数第1位切り捨て）。
