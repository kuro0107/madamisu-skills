# Agents

madamisu plugin 内で利用する agent 定義。
SKILL.md からは `${CLAUDE_PLUGIN_ROOT}/agents/<name>.md` 形式で参照する。

| ファイル | 役割 |
|---|---|
| `game-idea.md` | ゲーム性アイデア出し |
| `world-idea.md` | 世界観アイデア出し |
| `game-review.md` | ゲーム性レビュー |
| `world-review.md` | 世界観レビュー |
| `config-review.md` | 制作方針レビュー |
| `consistency.md` | 整合性チェック |
| `synthesis.md` | 資料まとめ |
| `proofread.md` | 校正 |
