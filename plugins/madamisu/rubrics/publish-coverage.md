# 網羅性チェック観点

## 観点A: 情報開示マトリクス vs 実資料の整合
- マトリクスに記載された情報が、実際にハンドアウトまたは証拠資料に含まれているか
- マトリクスの「開示タイミング」と資料の「提示タイミング」が一致するか
- マトリクスに無い情報が突然出てきていないか

## 観点B: GM資料の判定基準
- 各エンディング分岐の判定基準が明記されているか
- 想定外の状況への対応指針があるか
- 真相開示の手順が明確か

## 観点C: ルール説明の完全性
- フェーズ構成の説明
- 勝利条件の説明
- 禁止事項の説明
- 特殊ルール（密談・投票等）の説明

## 観点D: ハンドアウトの最低限要素
- 各ハンドアウトに公開情報・秘密情報・目的・所持情報・初期状態が揃っているか

## 出力フォーマット

各項目: [観点X] 欠落内容 / 該当ファイル / 補完案

最終行に記載: 欠落数: N件

## 情報の機能性（P8）

- [ ] 各提示情報（証拠カード本文・HO項目）がヒント目的に対し過不足なく寄与している
- [ ] ノイズ（推理に寄与しない数値・設定の開陳・データシートの丸写し）が無い
- [ ] 数値・詳細はそれ自体がヒントとして機能する場合にのみ含まれている
- [ ] 多段ヒントが突合で解ける（かつ過剰に解けなさすぎ＝勘投票化していない）
- [ ] プレイヤー提示情報とGM用情報（真相・運用注意）が分離されている
