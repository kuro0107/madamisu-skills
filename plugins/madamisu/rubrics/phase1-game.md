# Phase 1 ゲーム性レビュー観点

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 推理可能性（10点満点）

- [ ] 事件の概要から真犯人の存在が示唆されている
- [ ] 主要な手がかりが3つ以上設計されている
- [ ] プレイヤーが推理ロジックで真相に到達できる導線がある
- [ ] 物理的に成立する犯行手段が記述されている
- [ ] 動機を示唆する設定が明示されている
- [ ] 真犯人を絞り込める排除ロジックが設計可能
- [ ] 重要な気づきポイントが事件概要に内包されている
- [ ] 推理を阻害する不合理な制約がない
- [ ] 真相到達に運や直感が必須ではない
- [ ] 結末に至る推理パスが論理的に説明可能

## 公平性（10点満点）

- [ ] 各プレイヤーが「確定的に」情報を取得できる手段が設計されている（P2: 成果不確定のフリー探索でない）
- [ ] 真犯人だけが極端に有利な情報を持たない
- [ ] 真犯人を特定するために必要な前提知識が外部依存していない
- [ ] 「メタ推理」を強制する設計（特定のキャラだけ詳細など）がない
- [ ] 重要情報がランダム要素に依存しない
- [ ] プレイヤー間の経験差で勝敗が決まる構造ではない
- [ ] 情報は非対称に分散しつつ、真相到達に必要な手がかりは確定取得手段で揃う（P1+P2）
- [ ] 「知らないと無理」な隠し条件がない
- [ ] 嘘をついていいキャラと悪いキャラの境界が設計上明確
- [ ] エンディング条件が事前に推測可能

## 面白さ（10点満点）

- [ ] 事件の骨子に意外性がある
- [ ] どんでん返しが設計されている
- [ ] 真相発覚時にカタルシスを生む構造がある
- [ ] キャラクター同士の対立や葛藤の種が含まれる
- [ ] プレイヤーが感情移入できる動機の種がある
- [ ] 単純な「犯人当て」を超えるドラマがある
- [ ] 各キャラに少なくとも1つの見せ場の種がある
- [ ] テーマ性（このシナリオで描きたい何か）が読み取れる
- [ ] 真相が「ありきたり」ではない
- [ ] プレイ後に印象に残る要素が設計されている

## 独自性（10点満点）

- [ ] 元資料の独自要素が活かされている
- [ ] 既存のマダミスシナリオと差別化できる仕掛けがある
- [ ] 舞台設定がシナリオの核に影響している
- [ ] キャラクターの組み合わせに必然性がある
- [ ] 動機が陳腐ではない（単なる怨恨・金銭ではない深み）
- [ ] 「この設定でしかできない」要素が含まれる
- [ ] テーマと事件構造に有機的な関連がある
- [ ] トリックや構造に新規性または工夫がある
- [ ] エンディングが定型的ではない
- [ ] ジャンル特有の要素が活用されている

## マダミス性（10点満点）

TRPG的な遊ばせ方へのドリフトを検出する。`madamisu-principles.md` 参照。

- [ ] 全キャラが他人に隠す秘密を持つ前提がある（P1）
- [ ] 情報が意図的に非対称配分されている（P1）
- [ ] 手がかりが確定取得できる前提で設計されている（P2）
- [ ] 「全員協力で真相を探すだけ」の構造になっていない（P7）
- [ ] 各キャラに固有の個人目標・思惑の種がある（P7）
- [ ] 犯人が沈黙で特定されない配慮の余地がある（P4）
- [ ] 秘密の早期自白を抑止する動機の種がある（P5）
- [ ] キャラ間に対立・駆け引きの構造がある（P1+P7）
- [ ] 全開示・全員共創（TRPG的）に流れていない
- [ ] 投票/会話による決定論的解決が成立する構造である

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 5観点（推理可能性・公平性・面白さ・独自性・マダミス性）の平均値（小数第1位切り捨て）。
