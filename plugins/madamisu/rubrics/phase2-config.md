# Phase 2 制作方針レビュー観点

Phase 1 制作方針レビュー観点に加え、プロット詳細化での方針整合を評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 方針遵守度（プロット詳細）（10点満点）

- [ ] 雰囲気指定がプロット詳細の描写トーンに反映されている
- [ ] ジャンル指定がプロットの構造（推理寄り/ホラー寄り等）に反映
- [ ] 難易度指定が手がかりの密度・推理の複雑さに反映
- [ ] 重視軸指定が詳細化の重点（謎/キャラ/世界観/バランス）に反映
- [ ] PvP/協力指定が証拠分配・勝利条件設計に反映
- [ ] エンディング構成指定が真相詳細・分岐条件に反映
- [ ] 想定プレイ時間に対しプロットボリュームが適切
- [ ] GM有無指定がGM専用情報の有無に反映
- [ ] 作り込み粒度指定が秘密・動機の詳細度に反映
- [ ] 元資料準拠度指定（あれば）が新規追加要素の量に反映

## 固定要素・制約遵守（10点満点）

- [ ] Q12 固定要素がプロット詳細でも維持されている
- [ ] Q9 禁止事項に違反する詳細が追加されていない
- [ ] 元資料の主要要素がPhase 1から劣化していない
- [ ] 固定要素が「形式的登場」でなくプロットに組み込まれている
- [ ] 元資料の登場人物の性格・背景が改変されていない
- [ ] 元資料のテーマがプロットの軸になっている
- [ ] 新規追加キャラ（あれば）が元資料の世界観と整合する
- [ ] ユーザーが活かしたい要素が複数箇所で参照されている
- [ ] 詳細化で元資料の独自性が薄まっていない
- [ ] エンディングが元資料の方向性と整合する

## 構造整合性（10点満点）

- [ ] プレイ人数とキャラクター数が一致している
- [ ] PvP指定時、各キャラに勝利条件と妨害手段が具体的に設計されている
- [ ] 協力型指定時、共通目標達成条件が具体的
- [ ] ハイブリッド指定時、個人目的と共通目標が衝突しない設計
- [ ] エンディング数指定と詳細化されたエンディング数が一致
- [ ] GMありの場合、GM裁定の指針が明記されている
- [ ] GMレスの場合、自動進行手段（タイマー・分岐表等）が設計されている
- [ ] 各キャラの情報量が大きく偏っていない
- [ ] 真犯人だけが情報過剰/過少ではない
- [ ] 制作方針の重視軸に応じた重点配分になっている

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 3観点の平均値（小数第1位切り捨て）。
