# Phase 2 世界観レビュー観点（キャラクター深掘り）

Phase 1 の世界観をキャラクター詳細レベルで再評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 動機の説得力（10点満点）

- [ ] 各キャラの行動動機が事前情報から納得できる
- [ ] 動機が複層的（表層動機と深層動機がある）
- [ ] キャラの過去エピソードが現在の動機に繋がる
- [ ] 動機と性格・職業・立場が整合する
- [ ] 動機が「人間的」（記号的な悪人ではない）
- [ ] 各キャラに「守りたいもの」が明示されている
- [ ] 各キャラに「失いたくないもの」が明示されている
- [ ] 動機の根が事件以前から積み重なっている
- [ ] 動機がジャンル・舞台と整合している
- [ ] 動機が他キャラとの関係性に影響する

## 秘密の深み（10点満点）

- [ ] 各キャラに「事件に関わる秘密」がある
- [ ] 秘密が「ただ言いたくない」ではなく「言えない理由」がある
- [ ] 秘密の内容に階層がある（表向き・本音・真実）
- [ ] 秘密が他キャラの秘密と連動している
- [ ] 秘密がドラマ性を生む構造
- [ ] 真犯人以外も「嘘をつく動機」が設計されている
- [ ] 秘密の暴露が物語の山場になり得る
- [ ] 秘密の重さに強弱がある
- [ ] 秘密が事件発生のトリガーに関与する
- [ ] 秘密が真相と接続している

## 人間関係の複雑さ（10点満点）

- [ ] キャラ同士に複数の関係軸（仕事・私生活・過去等）がある
- [ ] 表面上の関係と裏の関係に差がある
- [ ] 利害が対立するペアが複数組ある
- [ ] 同盟関係や協力関係が設計されている
- [ ] 三角関係や四角関係など複雑な感情が含まれる
- [ ] 関係性が時間軸（過去から現在）で変化している
- [ ] 各キャラに最低2人との関係性が描かれている
- [ ] 関係性が事件の動機に影響している
- [ ] 関係性が真相解明のヒントになる
- [ ] 関係性に「修復不能な亀裂」または「修復可能な余地」が設計されている

## 見せ場の有無（10点満点）

- [ ] 各キャラに固有の見せ場シーンの種が設計されている
- [ ] 見せ場が他キャラの存在で成立する構造
- [ ] 真犯人以外のキャラにも「主役級の瞬間」がある
- [ ] 見せ場が事件の進行に組み込まれている
- [ ] プレイヤーが「このキャラを演じたい」と思える魅力
- [ ] 見せ場のトーンがキャラの性格と整合する
- [ ] 見せ場が単なる情報開示でなく感情を伴う
- [ ] 各見せ場に「最低でも1つの感情の山」がある
- [ ] 見せ場がエンディング条件と結びついている
- [ ] 見せ場の配分がキャラ間で偏っていない

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 4観点の平均値（小数第1位切り捨て）。
