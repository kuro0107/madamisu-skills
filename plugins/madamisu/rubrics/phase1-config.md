# Phase 1 制作方針レビュー観点

`output/_config.md` の各項目に対し、生成された資料がどの程度遵守しているかを評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 方針遵守度（10点満点）

- [ ] 雰囲気指定（Q1）が世界観・事件のトーンに反映されている
- [ ] ジャンル指定（Q1）に沿った要素が含まれる
- [ ] 舞台・時代指定（Q2）が世界観.mdに反映されている
- [ ] 想定プレイ時間（Q3）に対し設定の密度が適切である
- [ ] ゲームタイプ指定（Q4: PvP/協力/ハイブリッド）が事件構造に反映されている
- [ ] エンディング構成指定（Q5）に沿ったエンディング案が記述されている
- [ ] 難易度指定（Q6）に応じた手がかりの密度になっている
- [ ] GM有無指定（Q8）に応じた進行構造になっている
- [ ] 重視軸指定（Q10）に沿った設定の重点配分になっている
- [ ] 作り込み粒度（Q11）に応じた詳細度になっている

## 固定要素・制約遵守（10点満点）

- [ ] Q12「固定要素・活かしたい要素」がすべて反映されている
- [ ] Q9「制限・禁止事項」に違反する要素がない
- [ ] Q13「元資料準拠度」（指定時）に整合する
- [ ] 元資料の主要キャラクター（指定時）が登場している
- [ ] 元資料の主要設定（指定時）が活かされている
- [ ] 元資料のテーマ性が反映されている
- [ ] ユーザーが明示的に避けたいテーマが含まれていない
- [ ] 固定要素を「形式的に登場させる」だけでなく構造に組み込んでいる
- [ ] 元資料の独自要素が薄まっていない
- [ ] 元資料の世界観ルールが破られていない

## 構造整合性（10点満点）

- [ ] プレイ人数指定（Q7）とキャラクター数が一致している
- [ ] GMあり指定時、GM専用情報セクションが設計されている
- [ ] GMレス指定時、自動進行可能な構造になっている
- [ ] PvP指定時、各キャラに勝利条件の種が用意されている
- [ ] 協力型指定時、共通目標が明示されている
- [ ] ハイブリッド指定時、個人目的と共通目標が両立している
- [ ] エンディング数指定と実際のエンディング数が一致する
- [ ] 短編指定時、設定が散漫でない
- [ ] 長編指定時、内容が薄くない
- [ ] 初心者向け指定時、推理補助要素が含まれている

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 3観点の平均値（小数第1位切り捨て）。
