# Phase 2 ゲーム性レビュー観点（プロット）

Phase 1 のゲーム性をプロット詳細レベルで再評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## 真相到達可能性（10点満点）

- [ ] 真相を示す物的証拠が3つ以上具体的に設計されている
- [ ] 動機を示す情報がプレイヤー間で共有可能な形で配置されている
- [ ] アリバイ崩しに必要な情報が確定取得手段（カード配布・トークン取得等）で得られる（P2）
- [ ] 推理ステップが論理連鎖で繋がる（飛躍が2個以下）
- [ ] 主要伏線が事件発生前または序盤に提示されている
- [ ] 真犯人特定に必要な情報が複数プレイヤーに分散配置されている
- [ ] レッドヘリングが過剰でない（5個以下）
- [ ] キーとなる気づきが資料中に明示されている
- [ ] 推理パスが2通り以上存在する
- [ ] エンディング条件達成が論理的に可能

## 動機の説得力（10点満点）

- [ ] 真犯人の動機が「殺人に至るほどの強度」を持つ
- [ ] 動機の根が複層的（単一要因でない）
- [ ] 動機を裏付ける過去エピソードが設計されている
- [ ] 真犯人以外のキャラの行動動機も納得感がある
- [ ] 動機と人物像（性格・職業・立場）が矛盾しない
- [ ] 「なぜそのタイミングだったか」の説明が可能
- [ ] 「なぜその手段だったか」の説明が可能
- [ ] 動機が陳腐でない（テンプレ的怨恨・金銭のみではない）
- [ ] プレイヤーが動機を推察できる手がかりが配置されている
- [ ] 動機がテーマと連動している

## 証拠バランス（10点満点）

- [ ] 証拠の総数が適切（プレイ人数×3〜5個）
- [ ] 各プレイヤーに最低1つは固有の重要証拠がある
- [ ] 物的証拠と証言証拠のバランスがとれている
- [ ] 偽の証拠（誤誘導）が明示的に設計されている
- [ ] 証拠の信頼度に強弱がある
- [ ] 重要証拠の発見条件が公平
- [ ] 各証拠がヒント目的を持ち過不足ない情報量で、必要に応じ多段で突合する（P8）
- [ ] 証拠が真犯人特定だけに偏らない（多角的）
- [ ] 真犯人だけが知る証拠が「秘密」として明示され、犯人HOには防衛用武器（嘘の供述材料・他人の秘密のフェイク）が用意されている（P4）
- [ ] 証拠が場所や時刻と紐付いている

## エンディングの満足感（10点満点）

- [ ] トゥルーエンドに到達した時のカタルシスが設計されている
- [ ] バッドエンド/サブエンドの分岐条件が明確
- [ ] エンディング間にテーマ的な対比がある
- [ ] 各エンディングが「ありそう」と感じる必然性
- [ ] エンディング後のキャラクターの末路が示唆される
- [ ] プレイヤーの選択がエンディングに影響する
- [ ] 「真相を知ったら見え方が変わる」描写がある
- [ ] エンディングが事件の動機と呼応する
- [ ] エンディングのトーンが制作方針指定と一致する
- [ ] エンディング数が制作方針指定と一致する

## マダミス性（10点満点）

プロット詳細レベルでTRPGドリフトを検出する。`madamisu-principles.md` 参照。

- [ ] 証拠・手がかりの取得が確定配布で設計されている（P2）
- [ ] 犯人HOの情報量が他キャラの1.5〜2倍を想定している（P4）
- [ ] 犯人に防衛用武器（カウンターロジック・フェイク情報）がある（P4）
- [ ] 各秘密・情報に公開レベル1〜5の想定がある（P3）
- [ ] 各キャラに個人勝利条件・ミッションがある（P7）
- [ ] 秘密の早期自白を抑止する仕組み（加点 or 社会的破滅）がある（P5）
- [ ] 情報が非対称に分散配置されている（P1）
- [ ] 本命/対抗の二重候補を犯人が提示できる証拠配置がある（メタ読み対策）
- [ ] 「全員協力で真相到達」だけに流れていない（P7）
- [ ] 投票/会話による決定論的解決が成立する（TRPG的ランダム解決でない）

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 5観点（真相到達可能性・動機の説得力・証拠バランス・エンディングの満足感・マダミス性）の平均値（小数第1位切り捨て）。
