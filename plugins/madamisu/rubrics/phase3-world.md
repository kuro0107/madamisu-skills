# Phase 3 世界観レビュー観点（ドラマ性）

タイムライン上のドラマ性と没入感を評価する。

各観点について、チェック項目を満たした数をスコアとする（10点満点 = 10項目中該当数）。

## ドラマ性（10点満点）

- [ ] タイムライン上に感情的な山場が設計されている
- [ ] キャラ同士の重要な邂逅・対立がタイムラインに含まれる
- [ ] 山場の前後に「予兆」と「余韻」が設計されている
- [ ] 山場の時刻に必然性がある
- [ ] 山場が事件のテーマと呼応する
- [ ] 山場が複数のキャラに影響する
- [ ] 山場が真相解明の重要な要素になる
- [ ] 山場の演出（場所・天候・時刻）が雰囲気を高める
- [ ] 山場が単なる情報開示でなく感情を伴う
- [ ] 山場のトーンが制作方針指定と一致する

## 伏線の配置（10点満点）

- [ ] タイムライン序盤に伏線が複数配置されている
- [ ] 伏線が後半で回収される構造
- [ ] 伏線が表面上は無関係に見える
- [ ] 伏線が複数の解釈を許す
- [ ] 真犯人を示す伏線が含まれる
- [ ] キャラの動機を示す伏線が含まれる
- [ ] 世界観の謎を示す伏線が含まれる
- [ ] 伏線が「あとから気づく」位置に配置されている
- [ ] 伏線の密度がプレイ時間に対し適切
- [ ] 伏線が制作方針のジャンルと整合する

## キャラクターの行動のリアリティ（10点満点）

- [ ] 各キャラの行動が性格と整合する
- [ ] 各キャラの行動が動機と整合する
- [ ] 各キャラの行動が職業・立場と整合する
- [ ] 「このキャラがこの時刻にここにいる理由」が説明可能
- [ ] 各キャラの行動間隔が現実的
- [ ] 食事・睡眠等の生理的時間が考慮されている
- [ ] キャラ同士の交流時間が自然
- [ ] キャラの感情変化が時間経過と整合する
- [ ] 唐突な行動転換に必然性がある
- [ ] キャラの行動が他キャラの行動に影響する

## 評価方法

各観点ごとに、上記10項目のうちチェック条件を満たす項目数を数える。
スコア = 該当数（0〜10）。

総合スコア = 3観点の平均値（小数第1位切り捨て）。
