以下の手順でmadamisu-publishの工程3（設計案ユーザー確認）を実行してください。

## 引数の解析

- `--v N` オプション: `PUBLISH_V`

## 入力ファイル読み込み

Read ツールで:
- `publish/v{PUBLISH_V}/02_game_design.md`
- `publish/v{PUBLISH_V}/02_info_disclosure_matrix.md`

## サマリ生成と表示

設計内容のサマリを以下のように整形:

```
========================================
工程2 完了

【フェーズ構成】（合計X時間Y分）
1. {フェーズ1名} ({時間}分)
2. {フェーズ2名} ({時間}分)
...

【難易度反映ポイント】
- 探索フェーズ数: N
- 手がかり総数: N個
- ミスリード密度: {低/中/高}

【特殊ルール】
- 密談: {内容}
- 投票: {方式}
- 勝利条件: {内容}

【エンディング分岐】
- {エンディング名}: {条件}
- ...

設計案を確認してください。
このまま進めますか？ [y/n/f]
  y: 工程4（資料作成）へ
  n: 中断
  f: フィードバックを反映する
========================================
```

## ユーザー入力後の分岐

- 「y」: 工程4へ進む（マスタースキル経由なら呼び出し元に戻る、単体実行時は終了）
- 「n」: 「処理を中断しました」と表示して終了
- 「f」:
  1. 「フィードバック内容を入力してください:」と表示してユーザー入力を受け付ける
  2. ユーザー入力を `FEEDBACK_INPUT` として記憶
  3. Skillツールで `madamisu:publish-step2` skillを起動。引数として `{INPUT_DIR}` `--v {PUBLISH_V}` `--feedback "{FEEDBACK_INPUT}"` を渡して実行
  4. フィードバック反映完了後、この工程3プロンプトに戻る（再度 `[y/n/f]`）

## 完了条件

ユーザー承認取得（y入力）。
